# Barkeep

AI bartender for Andrew's home bar: a rendered back bar of his real bottles (click to toggle stock), a retro tin robot that writes tonight's menu, and a "Make me a" counter that serves drinks on or off that menu.

> Shared infra conventions (Vercel org, Supabase `personal-shared`, morsenza.com, PR workflow) live in `~/personal/CLAUDE.md`. This file covers only what is specific to Barkeep.

## Stack

- Next.js (App Router, TypeScript), Tailwind v4, `next/font/google` (Fraunces + Alegreya Sans)
- Supabase `personal-shared` (`pxevaaqtducqbivbsqfp`), tables `barkeep_bottles`, `barkeep_menus`, `barkeep_drinks`, `barkeep_jobs`, `barkeep_meta`. Schema in `sql/schema.sql`; the one-time seed in `sql/seed.sql` (generated by `scripts/seed-sql.ts` from `lib/seed-bottles.ts`).
- Passcode auth (`BARKEEP_PASSCODE`, cookie `barkeep_auth`). API routes other than `/api/auth` require the cookie.
- `CLAUDE_CODE_OAUTH_TOKEN` is Barkeep's own token (minted with `claude setup-token`); Lucille has a separate one.

## How the AI works (same pattern as Lucille)

No Anthropic API key. `lib/claude.ts` boots a `@vercel/sandbox` microVM, installs the Claude Code CLI on first run and snapshots it (snapshot id in `barkeep_meta`), then runs `claude -p <prompt>` under `CLAUDE_CODE_OAUTH_TOKEN` (minted with `claude setup-token`). Requests are async: `POST /api/menu` and `POST /api/make` insert a `barkeep_jobs` row, return 202, and finish under `waitUntil`; the client polls `GET /api/jobs/:id`. Claude is asked for a JSON object only; `lib/schemas.ts` strips fences and validates with zod.

Locally the sandbox needs `VERCEL_OIDC_TOKEN` in `.env.local` (`npx vercel env pull .env.local`, sandbox disabled); it expires, so re-pull when generation starts failing with an auth error.

Supabase keys must be the new-style `sb_secret_…` / `sb_publishable_…` keys; the shared project has legacy JWT keys disabled.

## Dev

```bash
npm run dev     # http://localhost:3000, passcode is BARKEEP_PASSCODE in .env.local
npm test        # vitest, lib/**/*.test.ts
npm run build
```

Running SQL against the shared project: `SUPABASE_ACCESS_TOKEN=... node scripts/run-sql.mjs sql/file.sql` (token in `~/personal/home_inventory/.env.local`; run with the Bash sandbox disabled).

## Bottles

Each bottle carries a `style` (`shape`, `glass`, `liquid`, `label`, `labelText`, `accent`) drawn by `components/Bottle.tsx` from the nine silhouettes in `lib/bottle-shapes.ts`. The 57 seeded bottles have hand-authored styles; new ones get `lib/bottle-defaults.ts` defaults, adjustable in the Bottles drawer.
